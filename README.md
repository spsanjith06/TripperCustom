# Tripper Hunter (Custom Royal Enfield Tripper Pod Bridge)

This Android app connects directly to the stock **Royal Enfield Hunter 350 Tripper Pod** (`RE_DISP`) via Bluetooth Low Energy (BLE) and provides:
1. **Live Google Maps Turn-by-Turn:** Reads navigation notifications and displays maneuvers, distance, and ETA on the stock Tripper pod.
2. **Visual Roundabout Support:** Translates roundabout exit instructions directly to the pod's graphic icons.
3. **Caller ID Display:** Scrolls incoming caller's contact name on the pod when the phone rings.

## Instant Build via GitHub Actions
1. Push this folder to your GitHub account repository.
2. Go to the **Actions** tab on GitHub.
3. The build runs automatically and gives you the downloadable `TripperHunter-Debug-APK` directly to install on your phone!
